# Gift Sniper

Сбор и анализ цен на трёх маркетплейсах Telegram-подарков — **Portals**,
**Tonnel**, **MRKT**. Проект проверял одну гипотезу: можно ли систематически
зарабатывать на перепродаже подарков, покупая лоты дешевле рыночной цены.

**Ответ: нельзя.** Ниже — как это измерено. Все данные, код и расчёты открыты.

## Главный результат

Смоделирован идеальный сценарий, лучше которого не бывает: покупка ровно по цене
состоявшейся сделки, продажа ровно в следующую состоявшуюся сделку по такому же
товару, без ограничения по времени и без конкурентов.

| Ценовой сегмент | Сделок | В плюсе | Медиана | Итог |
|---|---|---|---|---|
| до 30 TON | 293 | 8% | −2.0% | −129 TON |
| 30–100 TON | 269 | 12% | −2.0% | −222 TON |
| 100–300 TON | 56 | 12% | −1.9% | −156 TON |
| 300+ TON | 21 | 9% | −2.2% | −175 TON |
| **Всего** | **639** | **10%** | **−2.0%** | **−681 TON** |

Медиана ровно −2% — это комиссия продавца. Цена товара между двумя
последовательными сделками не меняется: покупаешь по рынку, продаёшь по рынку,
платишь комиссию.

Причина в устройстве рынка: 3134 подтверждённые сделки разошлись по 2495 разным
товарам — **медиана одна сделка на товар за девять дней**. Это доска объявлений,
а не биржа.

Подробный разбор с методикой — в [СТАТЬЯ.md](СТАТЬЯ.md) и [ИТОГИ.md](ИТОГИ.md).

## Данные

Собрано за 5–23 сентября 2026:

- 54 447 лотов с характеристиками;
- 1 811 271 изменение цены с отметками времени;
- **4 420 подтверждённых сделок с ценой** — площадки историю сделок не отдают,
  такой набор собирается только непрерывным наблюдением;
- 3 352 записи бумажного журнала с результатами.

Описание полей — в [dataset/README.md](dataset/README.md).

## Что умеет система

- **Сбор** с трёх площадок в реальном времени: новые лоты, изменения цен,
  исчезновения, подтверждённые продажи.
- **Каскад из 13 фильтров** — каждый порог получен измерением на живых данных,
  а не подобран на глаз.
- **Межбиржевая сверка**: перед отправкой сигнал проверяется на двух других
  площадках, с учётом трёх разных схем комиссий.
- **Бумажный журнал**: три сценария одновременно, честная модель с комиссиями,
  вероятностью продажи и сливом непроданного. Реальные деньги не тратятся.
- **Telegram-бот**: уведомления и управление с телефона.
- **Сервер**: автозапуск, перезапуск упавших процессов, ежедневные отчёты,
  самодиагностика с оповещением.
- **634 автоматических теста.**

## Запуск

```bash
pip install -r gift_sniper/requirements.txt
cp env.example.ps1 env.ps1      # впишите свои токены
python -m gift_sniper.supervisor
```

Проверка состояния: `python health.py`
Отчёт за сутки: `python -m gift_sniper.digest`
Тесты: `python -m pytest gift_sniper/tests -q`

Подробнее — в [ОПИСАНИЕ.md](ОПИСАНИЕ.md). Развёртывание на сервере — в `deploy/`.

## Структура

```
gift_sniper/     система: сбор, фильтры, сверка, журнал, бот, сервер
  signals.py     каскад фильтров — единственное место, где решается,
                 что считать выгодным предложением
  cross_check.py сверка цены по двум другим площадкам
  paper_journal.py  бумажный журнал сделок
diag/            скрипты исследования: все расчёты из статьи
deploy/          установка на сервер
```

Полная история разработки, все измерения и причины каждого решения —
в [gift_sniper/README.md](gift_sniper/README.md) и [ARCHITECT.md](ARCHITECT.md).

## Оговорки

Что **не** проверялось: хранение подарков месяцами как коллекционного актива,
мгновенная автоматическая скупка в первые секунды, работа под конкретный заказ.
Эти направления не опровергнуты — они просто вне рамок исследования.

Портал Portals не требует токена: проверено, все нужные запросы проходят без
авторизации. Токен MRKT живёт несколько часов и обновляется командой в боте.
